# 跃练 · Airbag Coach

iPhone Safari 优先的单板气垫复盘测试版。纯静态网页，使用 GitHub Pages 托管，无需 Cloudflare、服务器或 Xcode。

## 使用

1. 用 iPhone Safari 打开已发布的 HTTPS 页面，可以添加到主屏幕。
2. 先导入现有 MOV / MP4 视频验证回放；可选择其中 0.5 至 60 秒的一跳。
3. 在设置中填写阿里云百炼北京地域 API Key，按需开启自动分析。Key 只在本次页面内存中，刷新后重新填写，建议使用短期临时 Key。
4. 固定手机在出发点后方，直接点击开始探测，无需选择或输入目标动作。
5. 人物检测首次加载需要时间。跟踪框出现后出发，回来查看回放和分析。

本地拍摄和回看不需要 Key。分析时网页直接将每秒约 12 张、最多 96 张带时间戳的 JPEG 画面发给千问，不上传完整视频，不经过本站中转。手动分析会确认发送与计费；自动分析需先在设置中开启。支持设置中的百炼视频理解模型；按型号适配普通、思考和 Omni 返回方式，只分析助滑、上台、起跳、腾空，不分析落地。将固定机位视为既定条件，不评价视频或建议补拍；先按助滑、上台、起跳、腾空分阶段分析，再在结尾返回总体分析：一项下一跳可执行的调整、选择理由和同一项调整的自检标准。旧报告保留在本机，重新分析可生成新版建议。页面显示 API 返回用量。只有已配置单价的型号显示免费额度抵扣前的标价估算，其他型号不套用旧单价；实际扣费以百炼账单为准。

## 自动识别动作

拍摄与本地导入都无需动作输入。分析时识别直飞、抓板、转体、转体抓板、其他或无法判断，并显示可见依据。这里只识别可见表现，不能知道用户原本想做但未完成的目标，不保证精确角度或抓板名称。识别与四阶段复盘共用一次请求，不单独调用模型分类。新版报告（schema 6）先分别返回转体与抓板的 yes/no/uncertain 及观察证据，程序组合最终类别，不采用模型直接给出的类别或总结。转体有或无都至少引用两个不同时刻，抓板有至少一帧、抓板无至少两帧；引用必须对应已发送画面、严格递增且不重复。缺失或非法依据降为无法确认，不能默认直飞；无效的其他动作依据也不会回退直飞。可展开动作识别依据逐帧回看。对证据完整性校验失败且没有上一跳重点的报告，暂不新增基于动作类别的纠正；已有重点则继续保留。

提示词明确：单帧侧身、摆臂、拧肩、板头俯仰及透视变化不能单独证明转体，抓板需要明确抓握接触；“没有发现”不能直接作为否定依据。程序只核对引用的结构和时间，并不独立识别姿态，也不能证明文字观察属实。真实误判率、漏判率及无法判断比例仍需真实视频对照验证。旧报告保持原判定，重新分析后才会使用新规则。旧版目标记录仍可回看，重新分析会使用自动模式。

## 逐跳训练重点

分析会在同一次模型请求中识别可见动作类型并提出一个下一跳的训练重点。自动带入上次成功分析的指令、自检标准及动作类型，返回“已做到、部分做到、尚未做到、暂时无法判断”。未确认做到时继续保留同一个重点；做到后可以巩固或选择一个新的重点。四阶段分析仍保留。这里只发送历史文字建议和本跳画面，不额外上传历史视频，也不据此断言用户尝试过或证明建议带来改善。

识别到明确不同的动作类型时重新选择重点；类型不确定时保留原重点并暂不判断完成情况；本地导入按导入顺序衔接。每份成功报告保存当时使用的重点快照，之后重分析或删除来源记录不会改变旧报告；失败与取消保留原报告。旧版报告仍可回看，也可为下一跳提供已有建议。

## 两跳对比

回看默认使用原速 1×，仍可切换 1/2 和 1/4 倍率。本机已有更早的同类动作分析时，回看页可打开“两跳对比”，自动选择最近的同类记录并排回放。只比较实际识别明确的直飞、抓板、转体、转体抓板；其他、无法判断及无有效动作识别报告的记录不参与；只有手动目标的旧报告需要重新分析后参与。

可以选择整跳，或选择两条报告都有有效时间依据的助滑、上台、起跳、腾空阶段。阶段回看按各自报告的参考点对齐短片段，整跳则各自从分析片段起点播放。参考点来自已有分析，属于辅助对照，并非精确姿态同步或改善结论；可使用各自视频控件检查细节。仅当对比记录就是当前报告保存的训练重点来源时显示该重点，避免将旧建议归给别的跳次。关闭、切换视频或删除时释放额外播放器资源。

对比直接使用浏览器中保存的视频和已有报告，不增加模型请求，不额外上传历史视频；四阶段分析和末尾总体分析保留。

## 拍摄和记录

- 固定后方机位，自动锁定目标，用缩小、远离、运动变化和消失延时估计结束；保留手动结束。
- 点击准备后仅侦测，确认约 5% 的持续局部运动才启动录像；等待期间不录像。相机晃动和变焦稳定期间暂缓运动判断。
- 等待出发不超时，自动录像至少 10 秒，结束估计后保留约 3 秒尾部；最长录像保护约 45 秒加尾部。自动结束是估计，不表示落地确认。
- 1/4、1/2、原速回放、片段循环、1/60 秒微步；微步不等同所有原片的精确逐帧。
- 视频和报告存在当前浏览器 IndexedDB；可下载原片、导出 JSON、删除。动作类型在分析时自动识别，无需输入。数据按应用路径分开命名。

保持屏幕解锁、页面在前台。切换应用或锁屏会尽力停止并保存，系统强制挂起或关闭时不能保证保存成功。浏览器存储可能被清理，重要录像请另行下载。换域名、换浏览器或从旧测试链接进入新链接，历史不会自动迁移。

## GitHub Pages 部署

仓库：<https://github.com/song-forever/airbag>

1. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
2. main 分支的推送会运行 `.github/workflows/pages.yml`，也可以在 Actions 手动运行。
3. 工作流运行测试、生成 `dist/`、校验资源并部署。成功后使用工作流显示的页面地址。标准项目地址为 `https://song-forever.github.io/airbag/`。

无需填写 GitHub Actions API Key 或其他 Secrets。每位使用者在页面输入自己的千问 Key。检测资源在构建时下载并检查 SHA-256，随页面一起发布；手机无需访问 Google 模型站点或 CDN。首次使用仍需下载资源，不保证离线。

GitHub Free 的 Pages 需要公开仓库；私有仓库需要支持 Pages 的付费方案。仓库私有不表示发布后的 Pages 网站私有，请检查 GitHub 的站点可见性。代码中不包含个人视频或真实 Key。

## 本地开发

Node.js 22+，无 npm 安装依赖。

```sh
npm test
npm run build
npm run validate
npm run dev
```

预览地址为 `http://localhost:4317/airbag/`，与实际项目路径一致。本机 localhost 可以使用相机；手机通过普通局域网 HTTP 访问不能启用相机，请使用已部署的 HTTPS 地址。

维护源码在 `src/`，静态发布内容在 `dist/`，构建脚本在 `scripts/`。首次构建需要访问固定的上游资源，后续可使用校验过的 `work/asset-cache/`。源代码不保存密钥、个人素材或检测二进制，构建产物包含所需二进制和第三方许可。

## 验证与限制

测试覆盖目标关联、遮挡、停止与超时、千问输入校验、错误、取消、结果与费用计算。已使用一段约 6.2 秒、720×1280 MOV 验证导入、解码和慢放。抽帧现按每秒约 12 张计算，该时长提取 75 张；长片段均匀抽取最多 96 张。请求不超过 15 MiB，必要时在本机压缩画面以满足体积预算；增帧会增加 Token 用量，可能跨越单价档位。API 请求流程使用明确的模拟响应测试，尚未使用真实 Key 验证千问结论、实际计费和延迟。

自动检测是实验功能；多人交叉、遮挡、远距离和移动机位会影响关联。iPhone 15 Pro Max 的实际拍摄帧率、发热、检测速度、结束时机及 Safari 直连千问，仍需手机现场验证。抽帧可能错过快速细节，AI 结论只作回看提示。

## 模型选择（2026-10-21）

当前列表按照提供的免费额度型号清单，与官方视频理解能力清单取交集，保留 31 个型号及版本。默认 qwen3.7-plus；优先组还包含 qwen3.8-max、qwen3.8-flash 和 qwen3-vl-plus。其余千问、开源视觉、Omni 和 Kimi 型号分组保留，同一系列的快照按准确 ID 区分。

移除未在所提供清单中的直供型号、Prime 等条目，移除文本、OCR、图片/视频生成、语音、向量和实时通话型号。模型选择只允许这 31 个 ID，不保留自定义或自动回退入口；不会把主线型号替换成其快照来假定共享额度。

模型清单在 src/model-catalog.js。网页不查询实时余额或保证调用免费；额度是否耗尽、过期及实际账单以百炼为准，请保留“免费额度用完即停”。不保存或发布账号额度、已用量、到期日期，也不上传原始额度清单。新增模型需要重新筛选后更新此列表。

能力依据：[视觉理解](https://help.aliyun.com/zh/model-studio/vision-model)、[Kimi](https://help.aliyun.com/zh/model-studio/kimi-api)、[Qwen-Omni](https://help.aliyun.com/zh/model-studio/qwen-omni)。当前使用带时间戳的抽帧，不发送音频；接口构造、流式解析、用量与边界测试使用模拟响应，不消耗用户免费额度。
